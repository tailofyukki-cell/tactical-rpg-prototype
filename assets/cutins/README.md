# Skill Cut-in Images

Put optional cut-in PNG files in this folder.

Current paths are configured in `data/cutins.json`:

- `rook.png`
- `nia.png`
- `mira.png`
- `raider.png`
- `cutpurse.png`
- `ash_shaman.png`

Recommended size:

- 480x180 PNG
- Transparent background if possible
- Character face or upper body framed toward the center

If a cut-in image is missing, the game still shows a stylized text cut-in using the unit name, class, and skill name.
