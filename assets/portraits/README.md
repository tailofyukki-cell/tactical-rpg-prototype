# Portrait Images

Put optional scenario portrait PNG files in this folder.

Current paths are configured in `data/portraits.json`:

- `rook.png`
- `nia.png`
- `mira.png`
- `boss.png`

Recommended size:

- 320x360 PNG
- Transparent background if possible
- Face or upper-body art

If a portrait image is missing, the game draws a placeholder portrait using the configured accent color.
